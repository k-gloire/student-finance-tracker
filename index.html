        About

        PRISM is a student finance tracker designed to help students manage daily expenses and make better financial decisions. Users can record transactions,organize expenses by category, search and sort records, and monitor spending through a dashboard and weekly chart.

        Our Purpose

        Managing money as a student can be challenging. PRISM makes it easier to understand spending habits, track expenses, and stay within a set spending limit.

        Technologies Used

        • HTML for semantic structure
        • CSS for responsive designand styling
        • Javascript for validation, search, sorting, and data management
